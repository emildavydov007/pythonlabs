## Описание

**MemeGenerator** — это десктопное приложение на Python, которое позволяет быстро и легко создавать мемы. Вы загружаете изображение, добавляете верхний и нижний текст, и программа накладывает текст поверх картинки в классическом стиле мемов.

Приложение имеет удобный графический интерфейс на базе `PySide6` и использует `Pillow` для обработки изображений.

## Функциональные возможности

- Загрузка изображений в форматах PNG, JPG, JPEG
- Ввод верхнего и нижнего текста
- Предпросмотр результата
- Сохранение готового мема в формате PNG
- Обработка ошибок (отсутствие изображения, несохранённый мем, неизвестные ошибки)

## Взаимодействие:

1. Пользователь нажимает кнопку → вызывается метод `MemeApp`.
2. Метод создаёт объект `MemeGenerator` (модель) и вызывает его метод `add_text()`.
3. Если возникает ошибка (нет картинки, проблемы с сохранением), выбрасывается кастомное исключение.
4. GUI ловит исключение и показывает сообщение через `QMessageBox`.
