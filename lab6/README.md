1. По своему варианту задания создайте пакет, содержащий 3 модуля, и подключите его к основной программе.

## Описание проделанной работы

была создана программа на Python для расчёта площади помещения и тепловой мощности.

Программа состоит из нескольких модулей, объединённых в пакет. Для интерфейса использовался Tkinter.
- `area.py`
- 
  Модуль отвечает за расчёт площади помещения.
  
- `heat.py`
- 
Модуль рассчитывает тепловую мощность

Используется формула:

Q=S⋅100

S — площадь помещения

100 — условное количество ватт на 1 м²

функция возвращает мощность отопления

- `models.py`
  
Модуль определяет коэффициент для типа помещения.
для разных помещений используются разные коэффициенты
функция возвращает нужное значение
